# GHC Study — three more independently checked worksheet terms (2026-10-14)

This batch is additional to `docs/GLOSSARY_VERIFIED_DEFINITIONS_20261014_BATCH7.md`. The headwords were read directly from `app/src/main/assets/glossary-data.js`, which indexes `Jägersprache1.xlsx`; that original worksheet was not re-fetched in this turn. The three definitions come from independently checked external, attributed resources rather than claimed verbatim GHC class slides.

| Indexed term | Verified English meaning | Direct references and scope |
|---|---|---|
| `Wildretter` (x158) | A *wildlife rescuer* (person) **or** a wildlife-saving deterrent or detector (device) depending on the context | Deutscher Jagdverband [Frühmahd tierschutzgerecht gestalten](https://www.jagdverband.de/fruhmahd-tierschutzgerecht-gestalten) explicitly uses `Wildretter` for wildlife-saving devices near mowing machinery; DJV [Kids für Kitze](https://www.jagdverband.de/kids-fuer-kitze-30-junge-wildretter-beim-naturschutz-und-jagderlebnistag) uses the term for human wildlife-saving volunteers and home-built visual/auditory deterrents. Not necessarily a single named device or professional title. |
| `Hirschlaus` (x116) | European deer ked, *Lipoptena cervi*; also `Hirschlausfliege` | Penn State Extension [Deer Keds](https://extension.psu.edu/deer-keds/) verifies the **European deer ked** English label, scientific name and blood-feeding deer parasite; independent [German Hirschlausfliege](https://hirschlaus.de/) site confirms that shortened **Hirschlaus** is used for the same insect. It is a fly, **not a true louse or a tick**. No disease-transmission claim. |
| `Marienkaefer` (x129) | Ladybird beetle; American English ladybug | [Langenscheidt dictionary](https://en.langenscheidt.com/german-english/marienkaefer) directly translates Marienkäfer as ladybird/ladybug in the Coccinellidae beetle family. This is ordinary nature vocabulary; GHC course-slide usage is not independently proven. |
