# Jungjäger-Wissen — Field Guide v1.5.1 (25 October 2026)

## Purpose and data inventory
Expands the existing GHC Study / Jäger Field Guide branch without removing any study data, species photographs, glossary records, question progress, or Trophy Test material. Adds a second top-level tab **Jungjäger-Wissen** alongside **Tiere · Animals**.

- Source: `app/src/main/assets/jungjaeger-data.js` — **41** compact German/English fact cards, no live API calls, grouped into six chapters: Brauchtum (8), Jagdhorn (12), Jagdarten (7), Sicherheit (5), Recht & Wild (5), Nach dem Schuss (4). Every card has a meaning, practical steps, explicit qualification and named course baseline plus an external source URL for connected reference.
- Rendering: `app/src/main/assets/field-guide.html` and `field-guide.js`. Independent free-text search and category filters, accessible detail view and Android hardware Back handling.
- Scope: German hunting etiquette and practical rules; Hessen focus. **Not a live season/permit status service.** Horn card titles and practical meanings are not a substitute for the hunt leader's signaled procedures. **No horn audio or fabricated musical notation** is included.
- Version: `1.5.1`, code `152`; regular app ID `org.ghcstudy.v141` and side-by-side debug install ID `org.ghcstudy.v146.standalone`.

## Evidence interpretation and remaining uncertainty
- Cards identified as `Tradition`/`Etiquette` are **not** presented as statutes; Streckenordnung, head orientation, placements, ceremonial order and branch handover vary regionally.
- Cards identified as `Safety rule` summarize specific SVLFG provisions but do not substitute for reading the original, receiving the Jagdleiter's briefing or following assigned Stand/Schussbereich.
- Some practical suggestions (arrival time, congratulation wording, local documentation) are **best practice from the course**, not enforceable universal German law.
- Equipment/season cards avoid blanket status or personal firing clearance; exact locality, current regulatory version, protected game and ASP control zones can change.
- No live horn recordings or music are bundled: verified signal names only. The DJV PDF confirms titles, not specific tunes or exact local command sequencing.
- No physical S23 Ultra installation, standalone app storage behavior or update-signing compatibility is verified without on-phone testing.
- Source file display labels and slide dates are based on accessible documents; no blanket line-by-line legal audit of historical lesson material was done.
