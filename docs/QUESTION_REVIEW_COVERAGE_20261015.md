## Repeatable index and guardrails

`scripts/build_question_source_audit_matrix.py` reads every exam-question record from the built app, uniquely inventories original pool and `sourceRefs`, stored pre-existing classroom-source tags, originally provided `classroomSupport` labels, reviewed original evidence if present, and risk-category triage. For each question it now records one of three labels: `source_compared_explanation_qualified` (17), `source_compared_key_conflict` (7), or `not_individually_factual_audited` (843). Unresolved original bank keys are never treated as certified correct.

Both Android workflows produce this matrix from source **and from the actual APK ZIP** and upload it as a JSON artifact. The matrix is a navigation and audit ledger. It **does not certify** course/source material that has not been opened, original translations, keyed Hessen answers, up-to-date regulations, or image accuracy/permissions. A user reading the matrix can identify exactly which questions were audited and prioritize the 843 unaudited remainder.
