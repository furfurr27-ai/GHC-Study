## Content provenance rules

1. v1.4.5 source APK in `app/src/main/assets/` is the functional baseline until full source parity is established.
2. Study-card `Details` and `Other Facts` may contain **only** facts supported by course-slide material; record deck ID and slide/page for each fact in the future structured-data migration.
3. Hessen question pool material and Jaegersprache glossary have separate provenance. Preserve German hunting-language terms with English glosses.
4. Do not present independent internet research as if it were a classroom slide fact. Do not embed whole-slide screenshots as study-card images.
5. This repository is **public** as of the 2026-10-08 GitHub metadata read, despite the old README saying private. Keep source documents in Drive and link by ID rather than copying course PDFs to this repository without an explicit distribution decision.
6. Older slide dates in names may not represent current legal requirements. Verify current laws separately when required.
